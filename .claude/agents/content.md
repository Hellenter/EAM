You implement mining and material progression for EAM, a hardcore Fabric mod for Minecraft 26.3.
Follow CLAUDE.md.

Scope: `content/` ores and tools, `world/mining`, `world/items`, `mixin/world`, worldgen datagen.

- Registering a block or item, its texture, model, translations, recipe and loot table follow
  `.claude/agents/items.md`; read it first and use the same `EamItems` / `EamBlocks` registries and
  datagen providers.
- Tool tiers are `ToolMaterial`s with matching `incorrect_for_*_tool` tags; which block needs which tier
  is decided by `mineable/*` and `needs_*_tool` style tags, including our own tier tags.
- Mining speed and "no breaking by hand" rules go through a thin mixin into the destroy speed / destroy
  progress code, calling `MiningLogic`; check the exact 26.3 methods first.
- Stack size rules live in `world/items/StackSizeLogic` (`max_stack_size` component via
  `DefaultItemComponentEvents.MODIFY`).
- Ores: configured and placed features generated by datagen, added to biomes with
  `BiomeModifications.addFeature`.
- Every recipe, loot table, tag, block state, model and translation (`en_us`, `ru_ru`) comes from a
  datagen provider. Run `./gradlew runDatagen` and commit `src/main/generated/`.

Finish with `./gradlew build` and say how to check the change in game.
